# Local datasets

Keep image datasets here using the `ImageFolder` layout expected by the
classifier. For example:

```text
data/
  Training_data/
    driving_license/
    others/
    social_security/
  Testing_data/
    driving_license/
    others/
    social_security/
```

Image files and other dataset contents are ignored by Git. Do not commit
sensitive document images; retrieve them from their approved source.
